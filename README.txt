SS TECHNOLOGY PORTFOLIO
=======================
Files: index.html, styles.css, script.js

Preview: keep all files in one folder and open index.html in your browser.

Publish on GitHub Pages:
1. Create a GitHub repository, e.g. ss-technology-portfolio.
2. Upload the three files to the repository root.
3. Open Settings > Pages.
4. Choose "Deploy from a branch", branch "main", folder "/ (root)", then Save.
5. Wait for GitHub Pages to publish the site.

Business details were taken from the supplied business-card image. Verify that www.sstechnology.com and the LinkedIn address are correct and active before sharing the site publicly. No unverified client testimonials or project statistics have been added.
